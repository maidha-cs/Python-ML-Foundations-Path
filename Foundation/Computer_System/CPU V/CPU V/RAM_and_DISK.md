# Topic 01: Computer Systems - RAM versus Disk

Understanding the difference between short-term working memory and long-term storage is crucial for managing system performance and data pipelines.

---

## 1. RAM (Random Access Memory) - "The Working Desk"
* **Role:** Temporary working memory used by the CPU to hold data and programs currently in active use.
* **Speed:** Extremely high speed for rapid read/write operations.
* **Volatility:** **Volatile** — all data is erased when the computer is powered off.
* **Typical Capacity:** 8GB, 16GB, 32GB.

---

## 2. Disk (SSD / HDD) - "The Filing Cabinet"
* **Role:** Permanent storage for the operating system, applications, source code, and datasets.
* **Speed:** Slower than RAM (though modern Solid State Drives (SSDs) offer high read/write speeds).
* **Volatility:** **Non-Volatile** — data persists even after the system is shut down.
* **Typical Capacity:** 256GB, 512GB, 1TB+.

---

## 3. Side-by-Side Comparison

| Feature | RAM | Disk (SSD/HDD) |
| :--- | :--- | :--- |
| **Persistence** | Temporary (Lost on shutdown) | Permanent (Saved until deleted) |
| **Speed** | Ultra Fast | Moderate to Fast |
| **Primary Use** | Active program execution | Long-term file storage |
