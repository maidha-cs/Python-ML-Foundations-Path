# Topic 01: Computer Systems - Formats & Execution (Binary/Text & Runtime/Compiler)

---

## 1. Binary versus Text Formats
* **Text Formats (`.txt`, `.csv`, `.json`, `.py`):** 
  * Human-readable, easy to debug, universally compatible.
  * Slower to parse and larger in file size.
* **Binary Formats (`.jpg`, `.pkl`, `.h5`):** 
  * Machine-readable (0s and 1s), compact in size, extremely fast for computers to load.
  * Not readable by human eyes directly without specialized software.

---

## 2. Compiler versus Runtime (Interpreter)
* **Compiler (e.g., C++):** Translates the entire source code into machine code *before* execution. Catches syntax errors early and runs blazing fast.
* **Runtime / Interpreter (e.g., Python):** Translates and executes code line-by-line. Highly flexible, ideal for interactive development and data science workflows.
